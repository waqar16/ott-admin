# Netlify Deployment Checklist

## Pre-Deployment

- [ ] Code is pushed to Git repository (GitHub/GitLab/Bitbucket)
- [ ] All tests pass locally (`npm run build`)
- [ ] Environment variables documented
- [ ] Mock mode enabled in `lib/config.ts` (USE_MOCK_DATA = true)

## Netlify Setup

- [ ] Netlify account created
- [ ] Repository connected to Netlify
- [ ] Build command set: `npm run build`
- [ ] Publish directory set: `.next`
- [ ] Next.js plugin installed

## Configuration Files

- [x] `netlify.toml` created
- [x] `next.config.js` configured with image domains
- [x] `package.json` has correct build scripts

## Environment Variables (Optional for Mock Mode)

For production mode (when USE_MOCK_DATA = false):

- [ ] NEXTAUTH_URL
- [ ] NEXTAUTH_SECRET
- [ ] STRIPE_SECRET_KEY
- [ ] NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
- [ ] WORDPRESS_API_URL
- [ ] AWS credentials (if using S3)

## Post-Deployment

- [ ] Site deploys successfully
- [ ] Home page loads
- [ ] Catalog page works with filters
- [ ] Premiere page displays correctly
- [ ] Blog page shows mock posts
- [ ] Kids Zone page loads
- [ ] Settings page accessible
- [ ] Admin page accessible
- [ ] Images load from configured domains
- [ ] API routes respond correctly
- [ ] Mobile responsive design works

## Optional Enhancements

- [ ] Custom domain configured
- [ ] SSL certificate active (automatic)
- [ ] Forms connected to Netlify Forms
- [ ] Analytics integrated
- [ ] Performance monitoring enabled
- [ ] Build notifications set up

## Common Issues Checklist

- [ ] Build errors? Check Node version (18+)
- [ ] Images not loading? Verify next.config.js domains
- [ ] API errors? Check function logs in Netlify
- [ ] 404 errors? Verify redirect rules in netlify.toml
- [ ] Slow builds? Enable caching in build settings
